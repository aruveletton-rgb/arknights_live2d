## 3. 线程 A 目标与完成定义

### 3.1 目标

交付 Windows 桌宠路线的样例版：

1. 无开发环境的 Windows 安装版和便携版能够启动、驻留托盘、透明置顶、拖动缩放并保存设置。
2. 加载许可明确的真实 Cubism 样例模型，完成待机、跟随、点击、表情、动作和音频驱动口型。
3. 通过项目后端完成登录、账号隔离、最近 30 天聊天历史、用户明确要求保存的长期记忆，以及中/日文文字与语音交互。
4. 按住说话、松开识别并发送；ASR、LLM、TTS 任一失败时按分项降级，不返回假成功。
5. 提供本地手动提醒、重复提醒、倒计时、通知/声音、查看/取消/延后，以及经用户确认后创建的自然语言提醒草稿。
6. 每个验收项都有可复核证据；未验证项明确标记为 `unverified`，不以 Mock 结果冒充真实能力。

### 3.2 不纳入本轮默认交付

目标角色替换、目标音色训练或定制、自动更新、代码签名、开机自启、鼠标穿透、摄像头、自主移动、macOS/Linux、B 路线浏览器交付，以及任何未在审计中追加的付费服务。
